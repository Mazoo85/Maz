      Real 3D cities

      See real buildings, trees and bridges in photo detail. The 3D models come from Google, which needs a free key of your own. You only do this once on each device.

      1. Open the Map Tiles API page, sign in, and press Enable. Google asks you to set up billing the first time.
      2. Open Credentials, press Create credentials, then API key.
      3. Edit the key. Under Application restrictions choose Websites and add mazoo85.github.io/*. Under API restrictions choose Map Tiles API. Save.
      4. Copy the key and paste it here.

      The key stays in this browser on this device. Each time you open the 3D view counts as one visit on your Google account. To be sure you're never charged, set a daily limit for the Map Tiles API under Quotas.
